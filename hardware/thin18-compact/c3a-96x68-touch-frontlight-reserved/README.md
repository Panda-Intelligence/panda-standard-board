# Thin18 compact C3A — touch/front-light reservation

C3A derives from C2 and makes no electrical changes. It reserves collision-free top-side space for J803, J804 and the front-light power cluster while the exact FPC connector geometry remains gated on the official display drawing.

Native checks: DRC=0, parity=0, ERC=0, unconnected=447 (expected; intentionally unrouted).
The exported netlist is semantically identical to C2 (same refs and pin/net tuples).

Not a manufacturing release.
