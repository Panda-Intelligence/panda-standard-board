# Split-C1 电池包与外壳采购输入（未发给供应商）

当前阶段只有两板 PCB 设计，没有实板；这是规格输入，不是已选定或获准采购的电池包。

| 项目 | 原型设计输入 |
| --- | --- |
| 电池包完整最大尺寸 | L54 × W36 × T5.5 mm，包含 PCM、包边、极耳和出线 |
| Core 坐标放置区 | x=1..37，y=11..65 mm；与 Display 投影 x=38..83 相隔 1 mm |
| 主电池容量 | 1100 mAh 名义目标，900 mAh 最小目标；续航需测，24h 要求仅指 RTC |
| 化学体系 | 1S 锂聚合物，3.7 V 名义 / 4.2 V 充电，带保护 |
| 保护后输出目标 | 连续 ≥1.5 A；峰值 ≥3 A / 3 s，须按批准温度与电压条件确认 |
| 原型充电上限 | 暂定 0.45 A；0..20°C 暂定 0.27 A；0..45°C 外禁止充电，最终以包厂和 TH301 曲线为准 |
| 电源线束 | 国产 HCTL HC-HY-2Y / HC-HY-T 配 J301 HC-HY-2AWT；AWG26，100..120 mm 初步路由 |
| 极性与 NTC | J301 pin1 BAT+ / pin2 GND；外置 TH301 接 J302，不并联未知包内 NTC |
| 国产身份 | 电芯、PCM 已装配器件、壳、端子均须精确厂家 / MPN；未选定 PCM 或整包 MPN |
| 外壳空间预算 | 112 × 75 × 19 mm；Core 96×68×0.8 与 Display 45×36×0.8，1.5 mm 板间隙 |

Z 预算：Core B=0；电池顶面=-1.8 mm，5.5 mm 包厚及 0.7 mm 膨胀预算使底面=-8.0 mm；后壁 0.8 mm 至 -8.8 mm。前侧为 Core 0.8 + J301 高度预算 5.5 + 装配 0.2 + 屏间隙 0.5 + 屏厚预算 2.2 + 前壁 0.8 =10.0 mm；再留 0.2 mm 制造预算，总厚 19.0 mm。

这些数值是工程预算，尚非供应商最大尺寸签核。电池区下移至 y11..65，避开背面 J503 原生本体包络（y4.975..9.025）；实际插接天线线缆仍需建模。H804 位于电池 XY 内，不能放未经审查的穿入电池包安装柱；背面器件/紧固件必须在 1.5 mm 预算内。屏幕 FPC、锁扣工具、USB 和卡槽通道、天线、喇叭、支撑及热条件仍需完整 CAD 验证。现有 0.2 mm 电源支路及过孔不能因连接器额定 3 A 就宣称整条路径通过 3 A。

EEMB [LP503450-PCM-NTC-LD/ 原厂编制规格](https://macrogroup.ru/upload/iblock/80a/i2bksi77p3ephpa70n95kv0izxtrs2jg/LP503450.pdf)（2017-11-13）给出整包最大 52×34.5×5.3 mm，可用于尺寸筛选；但其 PCM 仅 1 A 连续 / 2 A 三秒，使用进口 JST-ADHR-03V-H 和 45±5 mm 导线，NTC 曲线及 PCM 器件身份不明，未选用。需更新供应商完整图纸及精确国产包身份，不能直接采购这个旧版本。

[OpenSCAD 空间模型](SPLIT-C1-ENCLOSURE-STUDY.scad)显示两 PCB、侧置电池、膨胀区、屏厚预算和外壳空间框；没有真实壳体开孔或已验证实体模型。参考 XTEINK X4 Pro 的 5.95 mm 厚度不适用于当前堆叠，未声称达到。当前 EVT 仍为 NOT_RUN。
