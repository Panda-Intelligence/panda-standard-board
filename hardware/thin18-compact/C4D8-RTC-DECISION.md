# Split-C1 国产 RTC 与 24 小时备援设计
2026-10-02。当前只有 Core-C1、Display-C1 两板设计，没有真实样板。U302、C301 已实施国产原型 ECO；24 小时断开 USB／主电池后仍保持有效时间的要求不变。整机阅读续航是另一项指标。

| 位号 | 当前精确选择 | 设计改变 |
|---|---|---|
| U302 | WAVE SD3078 / C916255 | 8脚208mil宽体SOP；引脚／符号／旁路／PCB走线全部重做 |
| C301 | KAMCAP SE-5R5-D105VYH / C118887 | 1F、5.5V、水平通孔可充电超级电容；SMT之后手工焊接 |
| R303、R304 | 已移除 | 撤销未使用EVI和备援短接支路；不存在10k备援负载 |

[SD3078原厂Rev4.4](https://www.whwave.com.cn/filedownload/3045413)，SHA256 a11cb8cfb0cca2e2f44d137f7d1cff6a0ba4d2e7c7211c9058fa967b95c9231c。厂家为深圳市兴威帆电子技术有限公司。原厂1SCL、2F32K、3VDD、4NC、5VBAT、6GND、7INT、8SDA。F32K/NC不连接，INT保持共享开漏EXP_INT。VDD2.7..5.5V、VBAT2.3..3.6V；3.3V总线使用100kHz、7位地址0x32。备援0.8µA只是25°C典型值，未发布最大值；MSL3。原厂最大安装高1.9mm。焊盘2.0×0.7mm、1.27mm脚距、两行中心距7.3mm为依据尺寸推导的工程焊盘，不是厂家推荐焊盘。

[电容原厂2017规格](https://atta.szlcsc.com/upload/public/pdf/source/20170717/C118887_1500269960558820748.pdf)，SHA256 6d92dd32a36495c143b8f52239bd25e68c7dab187ff1b00b9b4db54cdd689dbb。KAMCAP为锦州凯美能源有限公司。精确H水平型号不能换成VYV立式。容量−20/+80%，本体最大直径19.2mm、高6.0mm，引脚19±0.5mm、直径1.0±0.1mm。工程焊盘2.4×2.0mm／镀通槽1.8×1.4mm，19mm间距。原厂图未编号极性：工程pin1=正，实际有正极标记的端子必须对准PCB“+”；不按文字朝向猜极性。

C301在(58.9,43.5)，U302在(73,27.5)。C302保留100nF VDD旁路，移到RTC附近。旧EVI/备援铜和悬空线撤销，I²C避开新电容孔；冻结铜图及源哈希见split-c1-rtc-layout.json。当前／基线重建的DRC、未连接、原理图一致性与ERC必须全部0。没有放宽铜间距或孔间距规则。

电容在SMT回流结束后手工焊接，原厂手焊260°C／5秒以内；本体离PCB暂留0.2mm，Core背面伸出引脚必须剪到≤0.5mm并检查毛刺、绝缘及1.5mm板间隙。新的前侧6.0mm本体预算将壳体空间框调整到112×75×20mm；不是可制造外壳或实物插接通过。

本节点是可充电超级电容，固件每次主电上电必须按原厂写保护顺序设置18H=0x82（充电允许、2kΩ）；禁止装一次性原电池。原型预充暂按6小时，但断电测试前必须实测VBAT≥3.15V，不能仅按时间推定充满。原厂内部3.3V充电电路没有给出本设计条件的最小终端电压或电容漏电上限，因此该起点是验收条件，尚非保证。

t = C有效 × (V起点−V终点) / I总。目标总备援电流≤2µA，含RTC、电容自放电、PCB污染／其他漏电；VBAT工作终点按2.3V。室温容量按1F×0.8×0.7老化预算=0.56F，条件估算66.11h；−25°C再按0.5容量=0.28F，条件估算33.06h。原先4µA在这个冷角只有16.53h，不能满足24h。2µA不是测量值或数据表保证；若实际节点电流超过目标、起点不足或批准寿命／温度条件更严，必须重新选源并改图。电容声明−25..70°C，不可因RTC的−40..105°C宣称整套备援支持更宽范围。

驱动迁移契约见SPLIT-C1-RTC-FIRMWARE.md。仓库没有可集成的产品固件项目，文档不代表驱动已移植或测试。Q14仍须在样板后验证≥24h有效时间、起终电压、节点电流、RTCF/OSF/BLF及批准常温／冷／热／寿命条件；主电池、USB、调试器及信号不得反向供电。Q04–Q14全部NOT_RUN。
