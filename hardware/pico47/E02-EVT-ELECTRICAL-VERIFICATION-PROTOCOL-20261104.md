# Panda Standard 4.7" (E0.2 R48) EVT 电气测试与温度标定规程

> **文档性质**：本规程覆盖待闭合实证项 G5（供电轨噪声与稳定性）、G6（墨水屏 PMIC 电荷泵瞬态与纹波）和 G7（TH801 温度曲线与测温精度），规定在真实样机上**测什么、在哪里测、怎么测、记录什么**。
> **基线绑定**：E0.2 R48（PCB SHA-256 `a22758f7f47e723b601897d3aeba711c0afc690e00a687a0eccac5029bbc028c`）。器件、网络与测试点均取自原理图实际网表；若后续修订改动这些对象，本规程须同步更新。
> **资格状态**：`actual_noise_and_stability_qualified` 与 `charge_pump_transient_and_ripple_qualified` 保持 `false`。本规程本身不是测试结果。
> **数值限值**：与[资格状态说明](E02-QUALIFICATION-STATUS-20261103.md)一致，目前**没有已批准的数值通过限值**（`numerical_acceptance_limits = null`）。下文所有标注“待定”的限值，必须先依据精确器件版本的数据手册与完整面板规格确定、写明出处并经工程批准，才能用于判定。不得用本文档旧版中的示例数字代替。

2026-11-06 修订：旧版第 1 节引用的 U401 (AXP2101)、J401、TP401、TP402、`VBAT`、`VSYS`、`3V3_SYS`、`1V8_LOGIC`、C408、C414、C421、U202 在原理图中均不存在，已按实际电源树重写；C808/C811 更正为 47 nF；TH801 测温链路更正为 U810 内部测温（不经 ESP32 ADC，也不是电池 JEITA 测温）；删除没有来源的限值、时序间隔和“实测证明”的精度数字。

## 0. 测试前提

1. 只在完成 SMT、BT301 后装及目检的样机上执行；记录样机编号、PCB SHA、实装 BOM 批次及 21 项客供料的实际批次。
2. 首次上电使用限流可调电源经 J301 供电（不接真实电池），限流值由工程负责人按负载预算书面确定；确认 `VSYS_RAW`、`3V3_AON` 正常后才允许接 USB 和真实电池。
3. G6 的全部测试先在**不接面板**的条件下确认高压轨可控、可关断，再接入完整 E0470A01 面板进行带载测试。未完成空载确认前禁止插接面板。
4. 所有原始波形（`.csv`/`.bin` 与截图）、仪器型号与校准日期、探头型号与接地方式、带宽限制设置一并归档。

### 1.2 仪器与探测方法

1. 示波器带宽与采样率须高于被测开关频率谐波的关注上限，具体数值写入记录。
2. 纹波测量使用弹簧地针（地线尽量短）或直接焊在被测电容两端的同轴引线，地线就近接到该电容的地焊盘；禁止使用长鳄鱼夹地线。
3. 每次测量记录带宽限制设置（全带宽与 20 MHz 限带各记录一组）、耦合方式与输入阻抗。
4. 负载阶跃使用可编程电子负载或板上实际负载（Wi-Fi 发射、SD 卡连续写入、面板刷新），记录阶跃幅度、上升斜率和周期。

### 1.3 测试工况

| 工况 | 定义 | 需记录的轨 |
| :--- | :--- | :--- |
| A 待机 | U501 深度睡眠，可关断负载全部关闭 | `VSYS_RAW`、`3V3_AON` |
| B 典型运行 | CPU 全速，Wi-Fi 已连接，SD 空闲 | 1.1 表全部 |
| C 重负载 | Wi-Fi 连续发射，或 SD 卡连续块写入，或面板刷新 | `3V3_AON`、`3V3_RF`、`3V3_SD`、`VSYS_RAW` |
| D 充电 | USB 接入，真实电池或电子负载模拟电池 | `VBUS_USB`、`BAT_PACKP`、`VSYS_RAW` |

### 1.4 记录项与判定

对每条轨、每个工况记录：稳态峰峰值纹波、负载阶跃时的最大跌落/过冲及恢复时间、是否存在持续振荡。判定限值：

| 轨 | 纹波限值 | 阶跃跌落/过冲限值 | 恢复时间限值 | 限值出处 |
| :--- | :---: | :---: | :---: | :--- |
| 1.1 表各轨 | 待定 | 待定 | 待定 | 待填（器件手册条目／面板或负载芯片供电要求） |

### 1.5 启动与关断

1. 记录 `VSYS_RAW` → `3V3_AON_SRC` → `3V3_AON` 的启动波形，确认单调上升、无回落台阶；软启动时间与浪涌电流按 SGM62125 手册判定（限值待定）。
2. 分别切换 `EN_3V3_SD`、`EN_3V3_EPD_LOGIC`、`EN_VSYS_AUDIO`，记录负载开关输出的上升时间与 `3V3_AON`、`VSYS_RAW` 上的扰动。
3. 记录 `CHIP_PU` 复位与 `3V3_AON` 的时间关系，确认满足 ESP32-S3 上电时序要求（依据 ESP32-S3 数据手册的上电与复位时序要求）。

1. 记录实际上电顺序和各轨之间的延迟，与 SY7636A 寄存器配置的时序及面板规格要求的顺序逐项对照。要求的顺序和最小间隔**待依据**面板规格与 SY7636A 手册填写，本规程不预设。
2. 拉低 `P47_HV_EN` 后记录各轨下降过程，以及降到约定安全电压以下所需的时间；安全电压与时间限值待定。
3. 单独记录异常掉电（直接断开 J301 供电）时的泄放过程，作为风险记录。

## 3. 实证项 G7：TH801 温度曲线与测温精度

### 3.1 实际电路

TH801（FH `CMKD103F3380HANT`，0402，10 kΩ ±1%，B25/50 = 3380 K ±3%，见 [R44 说明](E02-R44-THERMISTOR-IDENTITY-20261103.md)）与 R806 (36 kΩ) 并联后，经 R805 (7.5 kΩ) 接 `P47_VREF`（U810 VREF pin 1，C815 100nF），分压点 `P47_TS` 接 **U810 TS（pin 47）**。这一路是 SY7636A 自己的测温输入，用于面板温度补偿；温度由 U810 内部转换，固件通过 I2C 读取温度寄存器。它**不经过 ESP32 的 ADC**，也**不是电池测温**（电池/充电测温走 `BQ_TS`，由 U901/U903 与 J302 处理，不在本节范围）。

```
P47_VREF (U810 pin 1)
   │
 R805 7.5 kΩ
   │
   ├──── P47_TS → U810 TS (pin 47)
   │
 TH801 ∥ R806 36 kΩ
   │
  GND
```

分压比与 VREF 电压无关：

$$R_{\text{NTC}}(T) = R_{25}\exp\!\left[B\left(\tfrac{1}{T}-\tfrac{1}{T_{25}}\right)\right],\quad R_{\text{TS}} = R_{\text{NTC}}\parallel R_{806},\quad k(T) = \frac{V_{\text{TS}}}{V_{\text{REF}}} = \frac{R_{\text{TS}}}{R_{805}+R_{\text{TS}}}$$

### 3.3 温箱标定规程

1. 样机置于温箱，TH801 附近贴参考热电偶或铂电阻（参考传感器型号、校准证书编号写入记录）。
2. 在适用工作温区内选取若干温度点（温区与点数由面板工作温度规格确定，至少含低、中、高三点），每点稳定后同时记录：参考温度、`P47_TS` 实测电压、`P47_VREF` 实测电压、U810 温度寄存器读数。
3. 由实测 $V_{\text{TS}}/V_{\text{REF}}$ 与 3.2 节理论值比较 TH801 网络本身的偏差；由 U810 读数与参考温度比较整条测温链路的误差。
4. 如需固件修正，修正方法与系数来源写入固件文档；修正后的精度只能以实测数据表述，并注明样本数量。
