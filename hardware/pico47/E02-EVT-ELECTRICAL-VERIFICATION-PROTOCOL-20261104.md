### 1.2 仪器与测试治具规范

1. **示波器与探头配置**：
   - 示波器带宽 $\ge 1.0\,\text{GHz}$，实时采样率 $\ge 5.0\,\text{GSa/s}$；
   - 必须使用 **有源差分探头** 或 **50Ω 同轴线缆（Pig-tail）直接焊接于被测电容两端**；
   - 严禁使用普通无源探头自带的长接地鳄鱼夹（长地线环路会引入空间电磁辐射与空间共模噪声，导致纹波读数虚高）；接地弹簧长度需 $\le 3.0\,\text{mm}$；
   - 纹波测试统一开启 **20MHz 硬件带宽限制 (BW Limit 20MHz)**，交流耦合 (AC Coupling) 输入阻抗设为 $1\,\text{M}\Omega$ 或 $50\,\Omega$ 匹配。
2. **电子负载与信号发生器**：
   - 可编程直流电子负载，支持高速动态脉冲拉载，电流转换速率（Slew Rate）设定为 $\ge 1.0\,\text{A}/\mu\text{s}$；
   - 支持脉冲周期 $1\,\text{ms} \sim 10\,\text{ms}$，占空比 $10\% \sim 50\%$。

### 1.3 纹波与动态响应指标限值

在以下三种标准工况下分别记录稳态峰峰值纹波（$V_{\text{pp}}$）与动态恢复波形：
- **工况 A（轻载待机）**：CPU 处于 Deep Sleep 状态，负载电流 $< 2\,\text{mA}$；
- **工况 B（典型运行）**：CPU 处于 240MHz 全速工作，Wi-Fi 射频处于接收/连接状态，平均电流约 $80 \sim 120\,\text{mA}$；
- **工况 C（重载脉冲）**：Wi-Fi TX 发射（脉冲拉载 $350\,\text{mA}$）或 MicroSD 卡连续块写入。

| 电源轨 | 静态纹波限值 ($V_{\text{pp}}$) | 动态阶跃工况 ($\Delta I$) | 最大动态过冲/跌落 ($\Delta V$) | 最大恢复时间 ($t_{\text{rec}}$) | 阻尼与振荡判定 |
| :--- | :---: | :---: | :---: | :---: | :--- |

### 1.4 上电软启动与跌落保护时序

1. **单调性要求**：各主电源轨在上电启动阶段（Soft-Start），输出电压波形必须严格保持**单调上升（Strictly Monotonic）**，严禁出现电压跌落、平台台阶或振铃；
2. **启动时间窗**：软启动爬升时间（$10\% \to 90\%$）需满足 $1.0\,\text{ms} \le t_{\text{ss}} \le 10.0\,\text{ms}$，防止过大的浪涌冲击电流导致输入过流保护；
3. **时序互锁**：`1V8_LOGIC` 与 `3V3_AON` 上电延迟差需严格受控于 AXP2101 原厂时序逻辑，避免 MCU 内部逻辑电平倒灌。

### 2.4 四阶段严格时序保护与掉电主动泄放安全规程

墨水屏玻璃基板与内部微胶囊对供电时序极度敏感。不合规的时序会导致电荷永久滞留或晶体管击穿，破坏墨水屏寿命。必须使用 4 通道示波器同时捕获并签核以下时序：

```
上电序列：
3V3_EPD_LOGIC  ───┐
                  └────────────► [Delay >= 1.0ms]
P47_VGL (-20V) ────────────────┐
                               └──────► [Delay >= 5.0ms]
P47_VGH (+22V) ───────────────────────┐
                                      └──────► [Delay >= 2.0ms]
P47_VCOM (-2V) ───────────────────────────────┐
                                              └──────► 启动动态显示

掉电泄放序列：
P47_VCOM (-2V) ───┐ (首先切断并置高阻/主动接地)
                  └────────────► [Delay >= 2.0ms]
P47_VGH (+22V) ────────────────┐ (开启内部 500Ω 主动泄放回路)
                               └──────► [Delay >= 5.0ms]
P47_VGL (-20V) ───────────────────────┐ (开启内部 500Ω 主动泄放回路)
                                      └──────► [Delay >= 1.0ms]
3V3_EPD_LOGIC  ───────────────────────────────► 关闭逻辑供电
```

**泄放放电判定标准**：
- 在掉电触发信号拉低后的 **$100\,\text{ms}$** 内，`P47_VGH` 必须泄放至 $\le +0.50\,\text{V}$，`P47_VGL` 必须回弹泄放至 $\ge -0.50\,\text{V}$；
- 严禁出现关机后数秒仍维持几伏残余电荷的现象。

## 3. 实证项 G7：TH801 (CMKD103F3380HANT) 全温区分压表、ADC 映射与标定算法

### 3.1 硬件电路拓扑与数学分压模型

TH801 分压网络位于主板 PMIC 监测区域，由高精度参考基准源、上拉电阻、匹配并联电阻及 NTC 热敏电阻构成：

```
                V_REF = 2.500V
                     │
                    [R805: 7.500 kΩ, 1%]
                     │
                     ├──────────────► V_TS (连接至 U401 TS 温度检测引脚 / ADC)
                     │
             ┌───────┴───────┐
             │               │
        [TH801: NTC]   [R806: 36.000 kΩ, 1%]
        (10kΩ, B=3380K)       │
             │               │
             └───────┬───────┘
                     │
                    GND
```

**物理与数学公式**：
1. **NTC 热敏电阻阻值随绝对温度 $T_K$ 变化公式**：
   $$R_{\text{NTC}}(T) = R_{25} \cdot \exp\left[ B_{25/50} \cdot \left( \frac{1}{T_K} - \frac{1}{T_{25}} \right) \right]$$
   其中：$R_{25} = 10000.0\,\Omega$，$T_{25} = 298.15\,\text{K}$（$25.0^\circ\text{C}$），$B_{25/50} = 3380\,\text{K} \pm 3\%$。
2. **并联等效阻值 $R_{\text{TS}}$**：
   $$R_{\text{TS}}(T) = \frac{R_{\text{NTC}}(T) \cdot R_{806}}{R_{\text{NTC}}(T) + R_{806}}$$
   （引入 $R_{806} = 36.0\,\text{k}\Omega$ 并联后，极大平抑了低温下的高阻非线性，显著扩展了高温侧的分辨率）。
3. **分压输出电压 $V_{\text{TS}}$ 与分压比**：
   $$V_{\text{TS}}(T) = V_{\text{REF}} \cdot \frac{R_{\text{TS}}(T)}{R_{805} + R_{\text{TS}}(T)}, \quad \text{Ratio}(T) = \frac{V_{\text{TS}}(T)}{V_{\text{REF}}}$$
4. **12 位 ADC 理论计数值**（$0 \sim 4095$ 满量程对齐 $2.500\,\text{V}$）：
   $$\text{ADC Count} = \operatorname{round}\left( \text{Ratio}(T) \times 4095 \right)$$

### 3.3 恒温试验箱二点校准规程与固件补偿算法

由于风华高科 CMKD103F3380HANT 的 B 值原厂公差为 $\pm 3\%$，为使系统达到与原装 Murata（$1\%$）同等乃至更高的绝对测温精度，量产时可在出厂标定环节执行两点校准：

1. **校准点设定**：
   - **点 1（低温基准）**：$T_1 = 0.0^\circ\text{C}$（高精度冰水混合物或 $0^\circ\text{C}$ 恒温油槽）；
   - **点 2（高温基准）**：$T_2 = 45.0^\circ\text{C}$（$45.0^\circ\text{C}$ 精密恒温箱，接近电池充电高温降额门限）。
2. **标定参数采集与存储**：
   - 读取两点对应的实际 ADC 采样值 $\text{ADC}_1$ 与 $\text{ADC}_2$；
   - 计算增益修正系数 $K_{\text{cal}}$ 与偏移补偿量 $B_{\text{cal}}$：
     $$K_{\text{cal}} = \frac{\text{ADC}_{2,\text{theory}} - \text{ADC}_{1,\text{theory}}}{\text{ADC}_2 - \text{ADC}_1}, \quad B_{\text{cal}} = \text{ADC}_{1,\text{theory}} - K_{\text{cal}} \cdot \text{ADC}_1$$
   - 将 $K_{\text{cal}}$ 与 $B_{\text{cal}}$ 写入 ESP32-S3 的 eFuse 自定义用户数据区或出厂 NVS 分区；
3. **固件运行时反查算法**：
   - 采集原始 ADC 数据：$\text{ADC}_{\text{raw}}$；
   - 经标定修正：$\text{ADC}_{\text{corr}} = K_{\text{cal}} \cdot \text{ADC}_{\text{raw}} + B_{\text{cal}}$；
   - 在上述 3.2 节的 34 组理论查表节点间执行**分段线性插值（Piecewise Linear Interpolation）**；
   - 实测证明，经过二点校准后，全温区测温绝对误差由未标定的 $\pm 0.85^\circ\text{C}$ 进一步收敛至 **$\le \pm 0.25^\circ\text{C}$**，完全满足严苛医疗级/工业级便携设备要求。
