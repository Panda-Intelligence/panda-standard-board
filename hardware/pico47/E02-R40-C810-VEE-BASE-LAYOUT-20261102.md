## 1. 走廊根因与零迁位三网（`P47_VEE_BASE` / `P47_VEE_DRV` / `P47_VGL`）联合重布

在 R38/R39 中，虽然 `P47_VREF`（`27.098 mm / 3 vias`）、`P47_VN_DRV`（`7.098 mm / 2 vias`）与 `P47_VN_LX`（`12.971 mm / 2 vias`）已完成收敛，但负压电荷泵储能支路 `U810.30 (VEE_BASE) -> C810.1` 仍被迫经 `(19.325, 96.20)` 与 `(19.275, 91.825)` 绕行 `B.Cu` 西侧外环（`X = 11.15..18.35 mm`）再经 `(14.50, 102.30)` 回到顶层，平面长度达 `22.623 mm`（空间导体长 `24.153 mm`，`3` 颗过孔，全网 `154` 条线段 / `48.687 mm`）。

几何诊断表明，阻塞 `U810.30 -> C810.1` 走直内层通道的根因并非器件位姿，而是通道资源分配：
- `P47_VEE_DRV`（`U810.28 -> C811.2`）占用了 `In2.Cu` 的 `X = 18.60..19.15 mm` 纵向走廊及下端过孔 `(19.15, 100.725)`；
- `P47_VGL`（`R803.1` 反馈分压采样支路）占用了 `F.Cu P47_VN_LX`（`Y = 97.625 mm`）、`In2.Cu P47_VN_LX`（`Y = 98.675 mm`）与 `B.Cu VSYS_RAW`（`Y = 98.45..99.10 mm`）之间唯一的局部过孔口袋 `(20.475, 98.15)`。

R40 在**不移动任何器件位姿**（相对 R39 保持 `moves = {}`，全部 265 件与 908 焊盘的位姿、UUID、值、字段与针网 100% 不变）的前提下，执行三网联合重布与冗余枝节清理：
1. **`P47_VEE_BASE`（`U810.30 -> C810.1 -> D804.2`）**：自 `U810.30 (18.45, 96.20)` 经顶层短引线至过孔 `(18.60, 96.975)` 转入 `In2.Cu`，沿 `X = 18.60..18.65 mm` 纵向内层走廊南下并西折至 `(15.40, 101.85)` 回到 `F.Cu` 直连 `C810.1 (15.75, 102.70)`；同时完整删除旧 `B.Cu` 西侧外环、北向悬空残枝及两颗旧过孔 `(19.275, 91.825)` 与 `(14.50, 102.30)`。`C810.1 -> D804.2` 顶层干线（`20.282 mm / 0 vias`）保持原样。
2. **`P47_VEE_DRV`（`U810.28 -> C811.2`）**：接管局部口袋过孔 `(20.425, 98.15)`，自 `U810.28 (18.45, 97.20)` 经 `F.Cu` 东出下穿至 `B.Cu` 并在 `(19.65, 100.375)` 回到 `F.Cu` 连接 `C811.2 (20.15, 100.60)`，释放 `In2.Cu` 西侧走廊。
3. **`P47_VGL`（`R803.1` `750k` 高阻采样分支）**：将 `R803.1 (20.60, 96.00)` 采样支路改由 `F.Cu` 东北向绕过 `R803/R804` 上沿，在 `(22.625, 96.675)` 转入 `In2.Cu` 东行至 `(25.325, 99.15)` 后汇入既有 `B.Cu` 采样线 `(25.392, 99.325)`，全网过孔总数保持 `7` 颗不变，且 `D804.1 -> C812.1`（`5.547 mm / 0 vias`）、`C812.1 -> R812.1`（`19.422 mm / 2 vias`）、`C812.1 -> J820.1`（`30.552 mm / 2 vias`）功率主干 100% 保持原样。
