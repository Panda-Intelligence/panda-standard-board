## Reusable source correction and tests

`pico47_route_groups.py` selects repair targets from original connected-pad
groups. For original `[{a,b},{c}]` and current `[{a},{b},{c}]`, only a/b is a
repair pair. Pin c was already open and must not become an incidental target.
Selecting the nearest groups of the entire net caused unnecessary collateral
routing in earlier attempts.

The helper rejects missing/overlapping groups, changed pad inventories, ambiguous
pad records and malformed evidence. It returns candidate pairs only: it cannot
approve or modify native CAD. The local planner uses it with additive-first
routing and a higher penalty for disturbing existing copper, then runs native
refill/DRC and physical connectivity checks before adoption.

negative cases. The same 18 tests were rerun from byte-identical copies in the
