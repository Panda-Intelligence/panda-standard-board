## 1. 制造背景与盘中孔 (Via-in-Pad / POFV) 选用必要性

### 1.1 架构与布局驱动因素
Panda Standard 4.7" 主板集成了双核 ESP32-S3 MCU、高压墨水屏 PMIC、锂电池充放电管理及高速 MicroSD 接口，且整机总厚度受到 $\le 7.00\,\text{mm}$ 的极端空间限制：
1. **高密度 QFN 与小封装扇出**：主控芯片 U501（ESP32-S3，QFN-56）及充放电芯片 U901（QFN-24）引脚间距仅为 $0.40 \sim 0.50\,\text{mm}$，外围密集排布 0402 阻容退耦件，板面无空间容纳常规“狗骨头（Dog-bone）”引线扇出；
2. **大电流与高频射频接地热沉**：U501 中心裸露散热焊盘（Pin 57 EP）承载高达 350mA 的 Wi-Fi 瞬态射频功耗，必须通过阵列过孔直通内层 In1 主地平面；
3. **沉板 Type-C 与大电流充放电路径**：J201、J301 与大电流滤波电容 C202/C207 直接承受高达 2A 以上的充放电电流，要求极低环路寄生电感。

### 1.2 为什么必须严格执行 IPC-4761 Type VII
若板厂在 SMT 表贴焊盘内的过孔未执行严格的 **Type VII（树脂塞孔 + 表面电镀盖铜平坦化，Plated Over Filled Via / POFV）**，将引发不可逆的生产灾难：
- **焊锡流失（Solder Wicking）**：在 SMT 回流焊熔融阶段，锡膏沿未封闭的孔道毛细渗吸至板底或内层，导致正面元器件引脚焊锡不足（Insufficient Solder）、虚焊或开路；
- **空洞超标与芯片散热失效**：QFN 裸露焊盘下的孔洞气化导致芯片底部空洞率（Voiding）超过 $30\%$，热阻急剧攀升致芯片热过载关机；
- **器件偏位与立碑（Tombstoning）**：两侧焊盘拉力不对称导致 0402/0603 元器件产生竖立或倾斜。

因此，**全板 46 颗盘中孔必须 100% 采用 IPC-4761 Type VII 工艺制造，严禁降级为阻焊油墨塞孔或开孔敞流**。

## 3. IPC-4761 Type VII 金相切片 (Micro-section) 判定标准

板厂随板出具的 IPC 仲裁试样券（Coupon）或首件板实切切片，必须在 $100\times \sim 500\times$ 光学显微镜下按以下标准判定：

```
                    表面沉金 (ENIG: Au 0.05um / Ni 3~6um)
                    ┌───────────────────────────────┐
                    │  表面电镀盖铜 (Cap Cu >= 12um) │  ◄── 凹陷 / 凸起 <= 10um
                    └───────────┬───────┬───────────┘
                                │       │
   孔壁一次镀铜 ───────────────► │ 树脂  │ ◄─────────────── 孔壁二次面铜
   (Barrel Cu >= 18um)          │ 塞孔  │                 (Barrel Cu >= 18um)
                                │ (TG   │
                                │>=150℃)│
                                │       │
                                └───────┘
```

### 3.1 树脂塞孔饱满度与平坦度 (Dimple / Bump)
1. **塞孔饱满度**：塞孔树脂（推荐采用三洋、太阳等专用非导电环氧树脂塞孔油墨，热膨胀系数 $\text{CTE} \le 30\,\text{ppm}/^\circ\text{C}$，玻璃化转变温度 $T_g \ge 150^\circ\text{C}$）填充率必须 $\ge 95\%$；
2. **表面平坦度极限**：
   - 表面凹陷深度（Dimple Depth）：**$\le 10.0\,\mu\text{m}$**（严禁凹陷造成焊膏沉积厚度不均）；
   - 表面凸起高度（Bump Height）：**$\le 10.0\,\mu\text{m}$**（严禁凸起造成元器件浮高）；
   - 研磨抛光后整体共面度误差受控在 $\pm 5\,\mu\text{m}$ 以内。

### 3.2 盖铜电镀层厚度与结合力 (Cap Plating Thickness & Adhesion)
1. **盖铜厚度**：过孔塞孔顶部的二次电镀盖铜层厚度必须满足 **$t_{\text{cap}} \ge 12.0\,\mu\text{m}$**（满足 IPC-6012 Class 3 严苛标准）；
2. **金属结合面**：盖铜层与孔壁一次铜及基板面铜的交界处，结晶需致密连续，严禁存在微裂隙、分层（Delamination）或微泡（Micro-voids）。

### 3.3 孔壁铜厚与内部空洞控制 (Barrel Copper & Voiding)
1. **孔壁铜厚**：孔壁镀铜平均厚度 $\ge 20.0\,\mu\text{m}$，任意单点最小厚度 $\ge 18.0\,\mu\text{m}$；
2. **树脂气泡控制**：切片横截面上，树脂内部的独立气泡面积总和不得超过通孔截面积的 **$5\%$**；
3. **红线禁令**：气泡严禁出现在孔口两端 $20\%$ 的深度范围内，严禁与孔壁铜箔接触。

### 3.4 热应力可靠性考核 (Thermal Stress Resistance)
- **试验方法**：依据 **IPC-TM-650 Method 2.6.8 Condition D**；
- **试验条件**：试样经 $260^\circ\text{C} \pm 5^\circ\text{C}$ 浮焊/回流焊热冲击，每次持续时间 $10\,\text{s}$，连续进行 **6 次循环**；
- **微观判定**：经 6 次热冲击后重新切片，孔壁拐角无断裂（Corner Cracking）、孔壁桶身无环向裂纹（Barrel Cracking）、盖铜与塞孔树脂无起泡脱层。

## 4. 板厂 CAM 工程问询 (EQ) 标准回复指南

为避免板厂 CAM 工程师反复提问或擅自变更工艺，特制定以下标准预案：

### EQ-1: 客户能否将 46 颗过孔由树脂塞孔盖铜 (Type VII) 变更为阻焊塞孔 (Type III / IV)?
- **工程答复**：**绝对禁止（STRICTLY REJECTED）**。
- **原因说明**：阻焊塞孔无法在其表面形成平整的金属化电镀铜层。在 SMT 贴片时，焊盘内部缺少铜皮支撑会导致锡膏大量流失，引发 U501 散热失效及 0402 阻容严重立碑虚焊。

### EQ-2: U501 中心 9 颗散热接地孔能否由板厂 CAM 改为外引“狗骨头”走线?
- **工程答复**：**绝对禁止（STRICTLY REJECTED）**。
- **原因说明**：U501 为高密 QFN-56 封装，周边已被 0402 退耦电容及射频走线完全占满；狗骨头外引将严重破坏内层参考地完整性，且大幅增加射频接地回流阻抗。

### EQ-3: 钻孔对位时，166 处偏心导线端点是否需要 CAM 工程师手动拉回过孔中心?
- **工程答复**：**严禁修改（DO NOT MODIFY）**。
- **原因说明**：166 处偏心走线端点已经过连续几何布尔交集核算，铜箔实体搭接宽度最小达 $0.0788\,\text{mm}$，完全满足电气导通与机械结合力；手动移动走线端点将破坏 $0.150\,\text{mm}$ 的电气安全间距。
