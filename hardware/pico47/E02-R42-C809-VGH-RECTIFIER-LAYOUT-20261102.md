## 2. `R41` 遗留的 `P47_VGH` 整流输出绕行问题与 `R42` 收敛方案

### 2.1 `R41` 中 `P47_VGH`（`D803.2 -> C809.1`）的拓扑缺陷

在 `SY7636A`（`U810`）双倍压电荷泵输出级中：
- 负压栅极轨 `P47_VGL` 的倍压整流二极管阴极 `D804.1` 与输出储能电容 `C812.1`（`1u/50V/0805`）在 `F.Cu` 同层直连（`5.547 mm`、`0` 过孔、`0.0064 Ω`）。
- 然而在正压栅极轨 `P47_VGH` 上，尽管倍压整流二极管阴极 `D803.2 (30.7000, 95.9375)` 与正压输出储能电容 `C809.1 (28.0000, 91.9500)`（`1u/50V/0805`）同样全部位于 `F.Cu`，且 `D803` 东侧 `X = 30.70 mm` 存在宽裕的 `F.Cu` 直通走廊（距 `D803.3 (29.7500, 94.0625)` 达 `0.95 mm`），`R41` 仍保留了早期遗留的双过孔底层绕行与东侧回折：
  1. **整流二极管至输出电容的双过孔 `0.15 mm` 底层绕行**：从 `D803.2 (30.7000, 95.9375)` 经 `0.15 mm` 细线向东进入 `VIA (31.2500, 95.6750)`，切换至 `B.Cu` 沿 `0.15 mm` 细线向南折返至 `(30.4500, 96.0500)` 再北上至 `(30.4750, 91.5750)`，穿过 `VIA (30.5000, 91.3750)` 回到 `F.Cu` 后才向西接入 `C809.1 (28.0000, 91.9500)`，导致 `D803.2 -> C809.1` 平面铜长达 `6.949 mm`（空间长度 `8.479 mm`）、跨 `2` 颗过孔、串联电阻达 `0.0174 Ω`。
  2. **`C809.1` 东侧过孔导致的下游二次折返与 `65` 段 `25 µm` 阶梯碎线**：由于 `C809.1` 的换层过孔位于其东侧 `2.57 mm` 的 `(30.5000, 91.3750)`，从 `C809.1 (28.0000, 91.9500)` 去往西侧 `U810.35 (VGH)`、`R801.1` 及南侧显示屏接口 `J820.3` 的全部电流必须先在 `F.Cu` 向东走 `2.57 mm` 到 `(30.5000, 91.3750)`，下穿至 `B.Cu` 后再向西折返穿过 `C809.1` 下方（`(30.50, 91.375) -> (27.875, 91.375)`），并在 `(27.875, 91.375) -> VIA (26.10, 92.55) -> (25.25, 90.825)` 与 `VIA (20.70, 91.95) -> (20.30, 93.375)` 处残留 `65` 段 `25 µm` 阶梯折线及 `2` 处非端点重合的圆头交叠。

### 2.2 `R42` 单网络收敛路径

`R42` 在不移动任何器件、不触碰任何其他网络的前提下，仅对 `P47_VGH` 实施三项干净收敛：
1. **`D803.2 -> C809.1` 全程 `F.Cu` `0.50 mm` 零过孔直连**：
   - 沿 `F.Cu` 45° 走廊 `D803.2 (30.7000, 95.9375) -> (30.7000, 93.2000) -> (29.4500, 91.9500) -> C809.1 (28.0000, 91.9500)` 采用连续 `0.50 mm` 宽铜轨直连（`0` 过孔，距 `D803.3` 净空 `333.7 µm`，距 `F.Cu` 异网最小净空 `>= 333.7 µm`）。
   - 保留 `D803.2 -> VIA (31.2500, 95.6750) -> TP801.1 (31.0000, 95.6750)` 背面测试点短桩完全不变，移除 `(30.4500, 96.0500) -> (30.4750, 91.5750)` 的 `4.476 mm` `0.15 mm` `B.Cu` 冗余纵贯支路。
2. **`C809.1` 换层过孔就近移至焊盘正南 `(28.0000, 92.8000)`**：
   - 将原东侧过孔 `(30.5000, 91.3750)` 移至 `C809.1` 正南 `(28.0000, 92.8000)`（`0.50/0.25 mm`，距 `C809.1` 焊盘边净空 `100 µm >= 50 µm`，四层对异网铜最小净空 `223.6 µm`），通过 `F.Cu` `0.50 mm` 短线 `(28.0000, 91.9500) -> (28.0000, 92.8000)` 直接汇入 `C809.1`，彻底消除东向 `2.57 mm` 往返折返。
3. **清理 `B.Cu` 与 `F.Cu` 阶梯碎线段**：
   - 将 `B.Cu` 上 `(30.50, 91.375) -> VIA (26.10, 92.55) -> (25.25, 90.825)` 的 `46` 段阶梯碎线收敛为 `5` 段 `0.50 mm` 标准 45° 走线 `[(28.00, 92.80), (26.35, 92.80), (26.10, 92.55), (26.10, 91.45), (25.475, 90.825), (25.25, 90.825)]`。
   - 将 `F.Cu` 上 `VIA (20.70, 91.95) -> (20.30, 93.375)` 的 `16` 段阶梯及圆头交叠段收敛为 `2` 段标准 45° 走线 `[(20.70, 91.95), (20.30, 92.35), (20.30, 93.375)]`，其余去往 `U810.35`、`R801.1` 及 `J820.3` 的全部走线与过孔保持逐位不变。
