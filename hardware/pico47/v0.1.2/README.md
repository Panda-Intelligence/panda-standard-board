# Panda Standard — Single 4-Layer PCB (`v0.1.2` / `R49`)

- **Board**: `Single.kicad_pcb`, 71.0 × 99.0 mm L-step four-layer board, R49 (= R48 layout + front-light supply fix).
- **Schematic**: `Single.kicad_sch`, readable wired schematic (see below). Same 265 parts, pins and 255 nets as the R49 netlist-style source.
- **Native checks** (KiCad 10.0.7, this directory alone): DRC 0 errors / 0 warnings / 0 unconnected / 0 schematic parity, ERC 0.
- **Rebuild**: `python3 build_pico47_single_r49.py --output <new dir under .work>` (KiCad Python) replays R26 → R48 → R49, writes this schematic and the JLC order pack; `--netlist-style-schematic` keeps the one-label-per-pin form.
- **Status**: `manufacturing_release = false`. Ordering prerequisites are listed in [R49 note](../E02-R49-FRONTLIGHT-SUPPLY-20261106.md) (46 Type VII via-in-pad CAM confirmation, 21 pending SMT parts, BT301 post-SMT).

## Changes vs. `v0.1.1`

1. R27–R48 layout revisions (see `../E02-R27-LAYOUT-FIXES-20261031.md` … `../E02-R48-XSTL-AND-CKV-BRIDGES-20261103.md`).
2. R49: the front-light boost input `VSYS_FL_IN` (L905 / R920 / C920) had no supply after the board merge; it now joins `VSYS_RAW` via a 0.40 mm, 29 mm link.
3. The schematic is regenerated by `../readable_schematic.py`: parts are grouped by designator hundreds (2xx USB/charge, 3xx battery/RTC, 4xx 3V3 and load switches, 5xx MCU/Flash/SD/audio, 6xx IO expanders, 7xx panel/SD muxes, 8xx EPD PMIC and panel, 9xx charger/gauge/front light) in titled frames; nets inside a block are drawn as wires, nets shared between blocks carry one global label per block, and GND / 3V3_AON / VSYS_RAW / I2C use labels at the pins. The build aborts if the regenerated netlist differs in any pin set or net name.

## Importing into EasyEDA Pro (嘉立创EDA专业版)

EasyEDA Pro documents KiCad import for versions below 10.0. These files are KiCad 10 format (PCB `20260206`, schematic `20250114`), so the import may be refused; copper zones are always rebuilt on import and must be re-checked. Fabrication itself only needs the Gerber / BOM / CPL from the order pack.

Symbols are generated rectangles with pins on both sides (the netlist-style source library); the library was not redrawn.
