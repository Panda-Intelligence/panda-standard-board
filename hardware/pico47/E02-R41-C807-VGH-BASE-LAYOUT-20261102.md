## 1. 走廊根因与零迁位单网（`P47_VGH_BASE`）精准收敛

在 R40 完成负压电荷泵储能电容 `C810`（`P47_VEE_BASE`，`U810.30 -> C810.1` 缩至 `7.953 mm / 2 vias`、`F.Cu + In2.Cu`）后，审计正压电荷泵对应支路 `P47_VGH_BASE`（`U810.34 -> C807.1 -> D803.1`，全网 `33` 条线段 / `27.919 mm` / `4` 颗过孔，跨 `['B.Cu', 'F.Cu', 'In2.Cu']`）发现三项历史遗留折返：

2. **`L801` 电感下方的东向折返环（`X = 17.545 -> 22.658 -> 17.545 mm`）**：旧支路在 `In2.Cu` 先向东北走至 `(22.6584, 92.4847)`，北上至功率电感 `L801` 下方的过孔 `(22.6584, 89.0896)`，随后在 `F.Cu` 又沿 `Y = 89.0896 mm` 向西折返 `5.114 mm` 至 `(17.5447, 89.0896)` 再前往 `C807.1 (14.40, 89.90)`，造成 `> 5 mm` 的往返绕行。
