# R44 TH801封装与名义温度曲线修正

2026-11-03，执行者：Codex。默认工程候选为R44。本次只修改TH801的精确MPN，保持所有器件和焊盘的原生ID、值、针网、位姿、焊盘形状、全板铜和规则。两次完整R26重建、默认入口及历史R43回归通过，三个R44独立原生审计确认范围，484个不同本地源用例互补通过。

原生R43中，TH801为FH `CMFA103F3950HANT`，但使用0402焊盘。风华原厂编制的[18.01版承认书](https://datasheet.lcsc.com/datasheet/pdf/a19ceb04b6f361e610a5c5fd800750bc.pdf?productCode=C47118797)（2019-07-11，第3–5页，经供应商镜像获取）明确尺寸代码A为0603、D为0402，现料号为10kΩ±1%、B25/50=3950K±3%。因此这里同时存在封装代码不匹配及名义温度曲线偏离；25°C阻值相同不能消除这两个问题。这份厂商历史文件不构成本项目来料或现行批次承认。

采用风华[官方高可靠片式NTC目录](https://www.fhcomp.com/en/product_page/?code=040303&page=7)中精确列出的`CMKD103F3380HANT`：0402、10kΩ±1%、B25/50=3380K±3%。没有按料号格式编造零件，也没有填写未经确认的LCSC或收货记录。物料保持FH厂家身份、0402尺寸类别及10k标称值，源`Value`仍为`10k NTC / CURVE TO QUALIFY`。

厂家编制的[CMK系列规格书](https://uploadcdn.oneyac.com/attachments/files/brand_pdf/fh/3D/B3/CMKB473F3950HANT.pdf)（供应商镜像，第1–2页）进一步确认D为1.0×0.5mm类别、A温度代码为25/50、F阻值精度为±1%、H的B精度为±3%，并明确列出0402系列的CMKD103□3380HANT。0402族本体外形为1.00±0.15×0.50±0.10mm、高度上限0.60mm；该族规格与精确目录行共同支持工程身份选择，仍不替代当前批次承认、完整R–T表或收货记录。

原生针网为TH801与R806的36kΩ并联，再经R805的7.5kΩ接VREF；TS接U810.47，地返回U810.48的实际参考地组。Silergy[历史Rev0.9B参考电路](https://datasheet4u.com/pdf/1547867/SY7636A.pdf)采用`NCP15XH103F03RC`及同一补偿网络；[Murata原厂资料](https://www.murata.com/-/media/webrenewal/products/thermistor/ntc/ncp/ncp15.ashx?cvid=20231225010000000000&la=en)给该参考件的B25/50为3380K±1%。R44只修正名义B值与尺寸类别，FH候选的B公差±3%比参考件±1%更宽，不能称为全温域等效替代或实际温度精度通过。

作为问题筛查，常B模型`R(T)=R25×exp(B×(1/T−1/T25))`配合该分压网络显示：旧3950模型相对3380模型，在0°C和50°C对应的历史线性换算读数差约−2.9°C与+4.1°C。这只是参数模型对比，不是两颗实际器件的全R–T表、当前PMIC误差保证、实测结果或EVT通过限值。必须取得精确NTC曲线、公差及现行PMIC数据，再验证自热、板到屏幕温差与多温点校准。

原理图、本地TH801封装库、原生PCB、构造器及大陆厂家元数据注册表同步更改这一项MPN；其它字段保持。ECO先校验原封装UUID、字段名和原值，全部前驱通过后才写字段；错误前驱不允许部分更改。历史R43源保留旧物料，R44温度契约严格拒绝0603/3950料号落在0402上，不通过放宽全局物料白名单维持历史回放。

新增原生温度网络检查锁定精确新MPN、0402焊盘签名、7.5k/36k精确物料及TS／VREF／地的实际连接组，不能仅用相同网络名替代实际地连接。检查结果中`exact_rt_curve_qualified`、`temperature_accuracy_qualified`、`supplier_receipt_accepted`仍为false；资格报告追加待签核温度曲线组，数值限值保持null。用户指定的制造、板厂工艺、实际噪声／稳定性和泵瞬态／纹波四项资格均保持false。
