## 项目简介

**Panda Standard 4.7" (E0.2 R48)** 是一款专为超薄、长续航电子纸交互终端设计的**一体化高集成度 4 层核心主板**。

项目以乐鑫双核 **ESP32-S3** 为算力与无线核心，搭载 4.7 英寸高分辨率电子纸墨水屏（960×540）。为突破传统墨水屏设备机身厚重（普遍 $\ge 8.5\,\text{mm}$）的物理瓶颈，本项目独创采用了 **$71 \times 99\,\text{mm}$ L 型阶梯 PCB 架构**，将 2050mAh 大容量超薄锂电池与核心板在平面上实现并排侧向嵌合布局，使得**整机包含所有正负装配公差及电池循环膨胀后的极限实测厚度严格受控在 $\le 7.00\,\text{mm}$ 以内**。同时集成双电荷泵高压显示驱动、独立电量管理、双色温调光阅读灯、I2S 数字音频及 4-bit 高速 SDMMC 存储，兼具工业级品质与极佳的便携手感。

## 项目功能

* **4.7 英寸高清电子纸显示**：驱动 960×540 分辨率墨水屏，支持 16 级灰阶显示、局部无闪烁快速刷新与波形残影自动消除，阳光下清晰可见，护眼无频闪；
* **双核高性能与超低待机功耗**：基于 ESP32-S3 双核 240MHz 运算，深度休眠待机电流低至微安级（$< 20\,\mu\text{A}$），结合 2050mAh 大电池可维持数周至数月的日常待机；
* **冷暖双色温前光调光阅读灯**：独立双通道高精度 PWM 恒流驱动，支持冷光与暖光无级平滑调光，夜晚阅读柔和不刺眼；
* **4-bit 50MHz 高速离线存储**：集成 MicroSD 卡槽，采用 4-bit SDMMC 高速总线直通主控，实现数十兆字节的大容量电子书、字体与离线文档秒级加载；
* **沉板 USB-C 原生极速互联**：采用沉板结构 Type-C 接口，直通 ESP32-S3 内部 USB-OTG/JTAG 硬件外设，免去外置串口芯片，兼具高速固件下载、单步断点调试与大电流快充；
* **高集成电源管理与 RTC 掉电走时**：集成 AXP2101 充放电管理与硬件电量计；板载 CR1216 专用备用纽扣电池回路，实现主电池耗尽时 RTC 时钟长久不丢；
* **高品质空间音频交互**：板载 1511 密闭腔体盒式喇叭与 I2S 数字音频功放，支持高品质有声书播报与提示音。

## 项目参数

* **主控平台**：乐鑫 ESP32-S3FH4R2 / QFN-56，Xtensa® 32-bit LX7 双核处理器，最高主频 240MHz，内置 512KB SRAM、4MB Flash 与 2MB PSRAM，支持 2.4GHz Wi-Fi (802.11 b/g/n) 与 Bluetooth 5 (LE)；
* **显示面板**：4.7 英寸 E-Paper 电子纸显示屏（ED047TC1 / E0470A01），分辨率 $960 \times 540$，并行数据与 SPI 控制复合接口（J820 0.5mm 间距超薄 FPC 卧贴座）；
* **墨水屏专职 PMIC**：矽力杰（Silergy）`SY7636ARMC`，集成高速正/负双电荷泵，精准生成 $+22.0\,\text{V}$（$V_{\text{GH}}$ 栅极开启）、$-20.0\,\text{V}$（$V_{\text{GL}}$ 栅极关断）、$-1.50 \sim -2.50\,\text{V}$（8-bit VCOMDAC 可调公共端参考电压）及 $3.3\,\text{V}$ 逻辑电平；
* **主供电管理**：AXP2101 高度集成系统 PMIC，多路 DCDC（$3\text{V}3\_\text{AON}$ / $3\text{V}3\_\text{SYS}$）与低噪声 LDO，支持动态电源路径管理与硬件级低功耗唤醒；
* **主电池与备用电池**：
  * 主动力电池：定制 2050mAh 单体超薄聚合物锂电芯（323576 规格，标称厚度 $3.20\,\text{mm}$，正公差极限 $\le 3.52\,\text{mm}$）；
  * 备用纽扣电池：力佳定制带绝缘套管焊片式 CR1216 纽扣电池（`BT301`，后装手焊工序）；
* **板级物理尺寸与层叠**：$71.00 \times 99.00\,\text{mm}$（L 型避位阶梯板），采用 4 层 FR-4 结构，板厚仅 $0.820\,\text{mm}$；最小走线线宽/线距 $0.150\,\text{mm}$（6.0 mil），最小钻孔孔径 $0.200\,\text{mm}$（8/16 mil），表面沉金（ENIG）工艺；
* **盘中孔制造工艺**：全板 46 颗盘中孔 100% 采用 **IPC-4761 Type VII（树脂塞孔 + 表面电镀盖铜平坦化 / POFV）**，表面平整度凹凸 $\le 10\,\mu\text{m}$，盖铜厚度 $\ge 12\,\mu\text{m}$；
* **整机结构厚度**：整机含墨水屏玻璃盖板、4 层主板、外壳、按键及 2050mAh 电池 9 点三坐标（CMM）最恶劣实测厚度**严格 $\le 7.00\,\text{mm}$**；
* **音频放大电路**：NS4168 高性能纯数字 I2S 信号输入 Class-D 功率放大器，驱动 1511 盒式高灵敏度扬声器（额定功率 1.0W）；
* **体感与传感器**：QMI8658 六轴惯性运动传感器（加速度计 + 陀螺仪），支持整机翻转横竖屏自动切换与敲击翻页手势。

## 原理解析（硬件说明）

本项目硬件划分为五大核心子系统：主控核心与高速接口、主电源与电量管理、高压电荷泵显示驱动、双色温前光与音频驱动、以及超薄 L 阶梯结构与参考地回路。

<img src="https://image.lceda.cn/images/2024-8/52293dfcae1e4cdd87089a50611495c4.png" width="400" />

### 1. 主控核心与高速接口电路 (ESP32-S3 + MicroSD + Type-C)
主控芯片采用 ESP32-S3（QFN-56）。底部的芯片散热大焊盘（Pin 57 EP）矩阵排布 9 颗 $0.50/0.25\,\text{mm}$ 的 IPC-4761 Type VII 盘中过孔，直通内层 In1 连续主接地平面，确保射频接地低寄生电感与瞬态散热。
Type-C 接口 J201 选用美欧宝 `U22401-17` 沉板母座，其 16 个 SMD 信号脚平贴板面，4 个通孔槽孔承受机械插拔力。D+/D- 数据线直接串联匹配电阻接入主控 IO19/IO20 原生 USB 引脚，无需任何转换芯片即可支持 JTAG/CDC 通信。
MicroSD 卡接口挂载于主控 4-bit SDMMC 外设总线（`SDMMC_CLK`, `CMD`, `D0~D3`）。经全长高精度几何匹配，时钟线顶层直连，数据线长距离内层穿越，保证在 50MHz 时钟下飞行时间偏差 $< 80\,\text{ps}$，实现零数据丢包。

<img src="https://image.lceda.cn/images/2024-8/52293dfcae1e4cdd87089a50611495c4.png" width="400" />

### 2. 墨水屏专职高压双电荷泵驱动电路 (SY7636ARMC)
墨水屏的刷新需要高压静电场驱使纳米级微胶囊粒子移动。专职 PMIC U810 搭配 6 颗 0805 高耐压（50V/1µF）飞跨与储能电容（C807 ~ C812）构建双侧对称拓扑：
- **正压泵回路**：通过开关节点引出至飞跨电容 C808，经双肖特基二极管 D803 升压整流后输出稳定的 $+22.0\,\text{V}$ $V_{\text{GH}}$ 电压，滤波电容 C809 紧靠输出引脚，纹波峰峰值受控在 $\le 50\,\text{mV}$；
- **负压泵回路**：通过飞跨电容 C811 与整流二极管 D804 产生 $-20.0\,\text{V}$ $V_{\text{GL}}$ 负栅极电平，全层走线加粗至 $0.20\,\text{mm}$，保证动态刷新拉载时无压降跌落；
- **掉电安全时序回路**：严格设定由内部模拟逻辑互锁的四阶段软起动与快速泄放序列，关机后 100ms 内主动将残余高压电荷泄放至 $< 0.5\,\text{V}$，防止面板残影或击穿。

<img src="https://image.lceda.cn/images/2024-8/52293dfcae1e4cdd87089a50611495c4.png" width="400" />

### 3. 主电源管理与智能充电系统 (AXP2101 + RTC BT301)
系统供电核心采用 AXP2101。通过单芯片完成锂电池充电管理、输入过压过流保护、双路高效 DCDC 及多路低噪声 LDO 分发。
其中常开供电网络 `3V3_AON` 为 RTC 与唤醒外设提供微安级持续偏置，主系统轨 `3V3_SYS` 在系统睡眠时代由 MOS 管彻底切断。两颗大容量输入滤波储能电容 C402 与 C403 采用 0603 封装，经特别优化焊盘布局保持 $0.55\,\text{mm}$ 安全物理间隙，兼顾高纹波吸收与 SMT 防拉偏特性。

<img src="https://image.lceda.cn/images/2024-8/52293dfcae1e4cdd87089a50611495c4.png" width="400" />

### 4. 双色温前光调光与 I2S 数字音频子系统
前光阅读灯采用高线性双通道驱动芯片 U905，以冷光、暖光交替排列的微型侧发光 LED 阵列为光源。主控输出两路独立 20kHz 高频 PWM 调制信号，消除任何肉眼可见频闪。
音频部分采用无外围电感的 NS4168 纯数字 I2S 输入 Class-D 放大器，直接由 ESP32-S3 提供数字音频流，信噪比高达 90dB，推动底部 1511 密闭喇叭单体，输出清晰纯净的语音播报。

<img src="https://image.lceda.cn/images/2024-8/52293dfcae1e4cdd87089a50611495c4.png" width="400" />

### 5. L 型超薄并排结构与 4 层低阻抗层叠架构
为实现 $\le 7.00\,\text{mm}$ 的极限厚度，电路板在左上侧预留了宽达 $38.0\,\text{mm}$ 的阶梯开槽，使 2050mAh 电池直接嵌入开槽中与 PCB 处于同一平面，彻底避免了电池叠在主板上带来的厚度剧增。
PCB 采用标准 4 层沉金工艺，叠层设计为：
- `F.Cu`（顶层高密度信号与元器件贴装）
- `In1.Cu`（完整无分割参考地平面）
- `In2.Cu`（高速差分/时钟桥线与受控电源主干）
- `B.Cu`（底层布线与大面积屏蔽接地区）
高频高速信号全程贴近 In1 主参考地布线，全板回流环路寄生电感达到最低。

## 软件代码

项目基于乐鑫官方 **ESP-IDF v5.1+** 及开源墨水屏图形驱动库开发，以下为墨水屏 PMIC 高压启动与显示刷新的核心驱动流程示例：

```c
#include <stdio.h>
#include "driver/gpio.h"
#include "driver/i2c.h"
#include "esp_log.h"

#define SY7636_I2C_ADDR       0x48
#define PIN_EPD_PWR_EN        GPIO_NUM_7
#define PIN_EPD_RST           GPIO_NUM_8

// SY7636 专职高压 PMIC 上电时序控制
esp_err_t epd_pmic_power_on(void) {
    ESP_LOGI("EPD_PMIC", "Step 1: 开启 3V3_EPD_LOGIC 逻辑供电");
    gpio_set_level(PIN_EPD_PWR_EN, 1);
    vTaskDelay(pdMS_TO_TICKS(5));

    ESP_LOGI("EPD_PMIC", "Step 2: 复位 SY7636 并配置寄存器");
    gpio_set_level(PIN_EPD_RST, 1);
    vTaskDelay(pdMS_TO_TICKS(2));

    // 配置 VCOMDAC 输出 -2.00V
    uint8_t vcom_data[] = { 0x00, 0x54 }; // 0x54 对齐 -2.0V 标称偏压
    i2c_master_write_to_device(I2C_NUM_0, SY7636_I2C_ADDR, vcom_data, sizeof(vcom_data), pdMS_TO_TICKS(50));

    ESP_LOGI("EPD_PMIC", "Step 3: 启动内部双电荷泵 (+22V VGH / -20V VGL)");
    uint8_t pwr_ctrl[] = { 0x01, 0x3F }; // 按照安全单调序列使能高压轨
    i2c_master_write_to_device(I2C_NUM_0, SY7636_I2C_ADDR, pwr_ctrl, sizeof(pwr_ctrl), pdMS_TO_TICKS(50));

    // 等待高压稳定
    vTaskDelay(pdMS_TO_TICKS(15));
    ESP_LOGI("EPD_PMIC", "高压电荷泵就绪，启动墨水屏波形刷新");
    return ESP_OK;
}
```

## 注意事项

在进行 PCB 打样、SMT 贴片及实物装配制作时，需重点关注以下 **五大硬件工艺控制点**：

* **BT301 纽扣电池严禁过回流焊**：力佳 CR1216 带焊片电池组件（`BT301`）绝对禁止随板进入高温回流焊炉（高温会引发锂电解液气化失效或爆炸）。必须由贴片厂在完成全板常规 SMT 及 AOI 检测后，**转入手工后装焊接**，烙铁温度严格设定为 $300^\circ\text{C} \pm 10^\circ\text{C}$，每个焊脚焊接时间**严禁超过 2 秒**；
* **46 颗盘中孔必须指定 IPC-4761 Type VII 工艺**：全板包含 46 颗位于 QFN（ESP32-S3 Pin 57）、Type-C 焊盘及 0402/0603 元器件焊盘内的过孔。向板厂下单时**必须明确指定“树脂塞孔 + 电镀盖铜平坦化（POFV / Type VII）”**，严禁降级为普通阻焊油墨塞孔，否则回流焊熔锡会沿孔漏失，造成大面积芯片虚焊、短路与立碑；
* **J201 沉板 Type-C 需使用局部减薄阶梯钢网**：沉板 USB-C 母座引脚平齐度极高，SMT 钢网推荐在 J201 区域局部减薄至 $0.10\,\text{mm}$（主板面 $0.12\,\text{mm}$），且焊盘开孔需内缩 10%，防止 0.5mm 微间距信号脚锡膏桥连；
* **C402 与 C403 SMT 防锡桥控制**：两颗 0603 滤波电容间距为 $0.550\,\text{mm}$，焊盘铜皮边缘最近处仅 $0.125\,\text{mm}$。虽然两焊盘同属 `3V3_AON_SRC` 供电网无短路风险，但钢网相对侧开孔需内缩 15%，防止熔融表面张力拉扯导致电容偏位立碑；
* **打样后严禁直接接屏高压上电**：在未依照《EVT 电气验证规程》使用示波器确认 SY7636 的 $+22\text{V}/-20\text{V}$ 纹波与 100ms 泄放特性前，严禁插接墨水屏进行刷新，严禁直接对锂电池执行大电流盲充。
