## 2. `R42` 遗留的飞跨电容网络几何缺陷与 `R43` 收敛方案

### 2.1 `R42` 中 `C808` / `C811` 关联三网络的遗留碎线与非端点交叠

在 `R40`–`R42` 完成负压底座 `C810`（`P47_VEE_BASE`）、负压驱动 `C811.2`（`P47_VEE_DRV`）、负压输出 `C812`（`P47_VGL`）、正压底座 `C807`（`P47_VGH_BASE`）及正压输出 `C809`（`P47_VGH`）收敛后，`SY7636A`（`U810`）双倍压电荷泵其余 3 条飞跨电容支路仍保留 `R26` 自动布线器遗留的 `25 µm` 阶梯碎线、重复叠加段及非端点重合的圆头交叠（cap-overlap）：
1. **`P47_VGH_DRV`（`U810.36 <-> C808.2`）**：
   - 全长仅 `6.857 mm` 的双焊盘网络被拆成 **`119` 段走线**（含 `108` 段 `25 µm` 阶梯线段），在 `F.Cu` 上 `(19.05, 92.60) -> (19.075, 92.625)` 处残留 `1` 条 `35.4 µm` 悬空度为 1 的短桩，在 `In2.Cu` 上残留 `2` 条 `1.7 µm` 重复极短线段及 `(20.775, 91.225)` 与 `(20.775, 90.9501)` 之间 `274.9 µm` 的非端点重合圆头搭接。
2. **`P47_PUMP_POS`（`C808.1 <-> D803.3`）**：
   - 全程位于 `F.Cu`（`0` 过孔），但包含 `38` 段走线（含 `28` 段 `25 µm` 阶梯线段），且在 `(21.775, 90.2209)` 与 `(21.775, 90.3000)` 之间存在 `79.1 µm` 的非端点重合圆头搭接。
3. **`P47_PUMP_NEG`（`C811.1 <-> D804.3`）**：
   - 包含 `27` 段走线（含 `18` 段 `25 µm` 阶梯线段），线宽混用 `0.15 mm` 与 `0.16 mm`，且在 `F.Cu` 与 `B.Cu` 上存在 `4` 处非端点重合的圆头搭接（间距 `92.2 µm`、`35.4 µm`、`125.0 µm`、`87.3 µm`）。

### 2.2 `R43` 零迁位三网络干净收敛

`R43` 在不移动任何器件、不新增或删除任何过孔（保留原有 `4` 颗过孔原位不动）的前提下，将 3 条飞跨电容网络全部收敛为端点精确重合的标准 45° 走线：
1. **`P47_VGH_DRV`（`119 -> 9` 段，`-110` 段，`2` 过孔不变）**：
   - `F.Cu` 北段：`C808.2 (22.30, 89.0896)`（`0.25 mm`）经 `(22.30, 90.40) -> (21.75, 90.95) -> VIA (20.775, 90.95)`（`0.20 mm`）；
   - `In2.Cu` 中段：`VIA (20.775, 90.95)` 经 `(20.475, 90.95) -> (19.05, 92.375) -> VIA (19.05, 92.60)`（`0.16 mm`）；
   - `F.Cu` 南段：`VIA (19.05, 92.60)` 经 `(19.05, 94.075) -> (18.40, 94.725) -> (17.545, 94.725) -> U810.36 (17.245, 94.425)`（`0.15 mm`）。
   - 彻底消除悬空短桩、重复线段、`274.9 µm` 非端点搭接及 `108` 段阶梯碎线。
2. **`P47_PUMP_POS`（`38 -> 10` 段，`-28` 段，`F.Cu` `0` 过孔）**：
   - 从 `C808.1 (20.60, 89.0896)`（`0.25 mm`）经 `(20.60, 90.025) -> (21.625, 90.025) -> (21.90, 90.30) -> (25.05, 90.30) -> (25.40, 90.65) -> (25.40, 90.975) -> (27.90, 93.475) -> (28.325, 93.475) -> (28.9125, 94.0625) -> D803.3 (29.75, 94.0625)`（`0.15 mm`），对 `L801.1`（`VSYS_RAW`）焊盘保持 `>= 175 µm` 净空，消除 `79.1 µm` 非端点搭接与 `28` 段阶梯碎线。
3. **`P47_PUMP_NEG`（`27 -> 7` 段，`-20` 段，`2` 过孔不变，全段拓宽至 `0.20 mm`）**：
   - 将原 `0.15 / 0.16 mm` 混合细线统一拓宽至 `0.20 mm`：`F.Cu` 上 `C811.1 (22.30, 98.175) -> (22.30, 97.725) -> (22.90, 97.125) -> VIA (26.275, 97.125)`，`B.Cu` 上 `VIA (26.275, 97.125) -> (26.625, 97.125) -> (29.75, 94.00) -> VIA (29.75, 92.85)`，`F.Cu` 上 `VIA (29.75, 92.85) -> D804.3 (29.75, 90.0625)`，彻底消除 `4` 处非端点搭接与 `18` 段阶梯碎线。
