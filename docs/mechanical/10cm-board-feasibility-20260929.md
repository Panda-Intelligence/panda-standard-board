# 进 10×10cm 的可行性方案（2026-09-29）

**结论：可以做,而且根因很明确 —— 现在用的是"屏模块"(129.33mm),换成同规格裸屏(105.33mm)就短了 24mm。**

| 项 | 现在 | 换裸屏后 |
|---|---|---|
| 显示件 | Waveshare 4.26" **模块**,外形 **129.33 × 62.37** | Good Display **GDEQ0426T82** 裸屏,外形 **105.33 × 62.37** ✓ |
| 分辨率 | 800×480（无损失） | 800×480 ✓ 同规格 |
| 板长 | **128.1 mm** ✗ | 目标 **≤100 mm** |
| 嘉立创优惠 | ✗ 尺寸超出 | ✓ 可进 10×10cm 档 |

---

## 一、为什么现在超尺寸（实测）

- 主板 **70.0 × 128.1 mm** = 围着**屏模块**做的框,中间还有 **60×68mm 腔体**(电池);
- 板长 128.1 ≈ 模块外形 129.33 → **板长完全由屏模块决定** ✗;
- 换句话说:**不是布板问题,是选件问题**。

## 二、关键事实：裸屏短 24mm（同分辨率）

| | Waveshare 模块 | **GDEQ0426T82 裸屏** |
|---|---|---|
| 外形 | 129.33 × 62.37 × 0.93 | **105.33 × 62.37 × 0.93** ✓ |
| 有效区 | 92.8 × 55.68 | 92.8 × 55.68（同） |
| 分辨率 / IC | 800×480 / — | 800×480 / SSD1677 |
| 前光 / 触摸 | 有 | **有（-FL01C 带前光,可加触摸）** ✓ |
| FPC | — | 24 pin / 0.5mm |

**⇒ 换裸屏不牺牲任何规格,板长上限直接从 129 降到 105。**

## 三、板子怎么排进 ≤100×100

三条同时成立才能进档,逐条给方案:

1. **板 ≈ 96 × 62–70mm**（面板 105.33 两侧各让 ~2.7mm 压到机壳边框上——**阅读器的屏是贴在面壳上的,不是贴在 PCB 上的** ✓,所以板不必跟屏一样长);
2. **电池移到屏后面**（当前 60×68 腔体占了板面积的 58% ✗）：屏 0.93 + 板 0.8 + 电池 3–4 ≈ 5.5–6mm,仍在 5.95mm 目标内 ✓;
3. **元件面积够**：现板可用元件面积约 2,700mm²;96×62 的板 ≈ 5,950mm²,即使再挖一个较小腔体也有余量 ✓（实测全板非开窗区 39% 空闲）。

| 项 | 影响 |
|---|---|

| 可复用 | 原理图 ✓ / 器件选型 ✓ / 层叠与规则 ✓ / 全部设计文档 ✓ / 工具链 ✓ |

| 屏料号 | 设计文档里**本就未冻结**（"WP1 尚未交付 精确料号/FPC 定义"）✓ → 现在换正是时候 ✓ |
| 成本 | 打样费省的是几百元;真正收益是**机身从 128mm 缩到 ~104mm**（比 XTEINK X4 Pro 的 111mm 还短）✓ |
| 未变 | 采购买料、EMC/SI 验证边界、`WIP / NOT FOR FABRICATION` |

## 五、建议的推进顺序

1. **先把屏定下来**（GDEQ0426T82 或其带前光/触摸版本）,拿到规格书与 FPC 图纸;
2. **机构先冻结新尺寸**（面壳贴合面、电池后置、板外形 96×62±）——**这步不定,布板没有意义**;
3. 再做**新板 layout**(原理图直接复用,重排+重布);
4. 目标:板 ≤100×100 → 走嘉立创优惠档(注意 4 层**必须绿油**、沉金面积 <20% ✓ 我们实测 5.4% ✓)。

**⚠️ 不建议**:为了省打样费而改布局 —— 打样费省几百元,重新 layout 的成本远大于此。**真正值得做的理由是"机身更小"**(对标 XTEINK)。
