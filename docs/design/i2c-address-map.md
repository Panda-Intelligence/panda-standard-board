# Panda 標準電子書板：I²C 位址表與匯流排域

日期：2026-08-10（USB／IRQ 同步：2026-09-08，Codex）
狀態：核心位址規劃；TUSB320LI已採GPIO模式工程候選、不占I²C地址；S-9四象限／漏電／動態資格仍待驗證
適用板號：`PANDA-STD-CORE-EVT`

本文件凍結核心板 I²C 位址分配、衝突解法與上拉域擁有權。所有位址為 **7-bit**。

當前硬體依據：[USB2 S-9 A-stage](lib/review/USB2-S9-A-stage.md)。正式CAD為149封裝／1566段／311via，
DRC 0/0/0、ERC 19；這不是bus上升緣、失電或台架資格通過。

---

## 1. 匯流排拓樸

單一 I²C 匯流排（`I2C_SCL`=GPIO14、`I2C_SDA`=GPIO15），跨板間連接器延伸至轉接板。

```
MCU ──┬── 核心板常供裝置（充電器、燃料計、RTC、IMU、擴充器）
      │
      └── 板間連接器 ──┬── 轉接板裝置（EPD PMIC、觸控、前光、轉接板擴充器）
                        └── 高壓域由轉接板獨立擁有（核心板不傳輸 HV／VCOM）
```

TUSB320LI OUT1/2→AUP2G07→TCA P16/P17 是 GPIO 狀態路徑，不是 I²C 分支；ADDR保持NC。

不使用 I²C 多工器／切換器。理由：位址在 §2 解衝突後全域唯一，無需分段；且多工器會增加深睡靜態電流與
一顆需自建符號的元件。**但**見 §5 的未上電節點約束。

## 3. 🔴 衝突一：BQ25628E 與 LSM6DSO32X 撞位址 0x6A

### 3.1 事實

| 裝置 | 預設位址 | 是否可改 |
| --- | --- | --- |
| BQ25628E 充電器 | 0x6A | **不可**。TI 在修訂中把位址從 0x6B 改為 0x6A，無 ADDR 腳 |
| LSM6DSO32X IMU | 0x6A（SA0 接地時） | 可，SA0 接 VDD → 0x6B |

兩者若同時採預設接法，會在同一條匯流排上撞位址。

### 3.2 已採解法

**LSM6DSO32X 的 SA0 拉高至 `Vdd_IO` → IMU 位址 0x6B。**

代價：無。SA0 是專用位址選擇腳，拉高不影響任何其他功能，也不佔 GPIO。

### 3.3 為何不反向解

BQ25628E 無位址選擇腳，位址由 TI 在矽層固定，且該值是 TI 修訂後的最終值。反向解不存在。

### 3.4 連帶注意：0x6B 曾是 BQ25628E 舊位址

BQ25628E 修訂歷史明載位址曾為 0x6B。若採購批次或韌體沿用舊文件假設 0x6B，會與 IMU 的新位址 0x6B 相撞。

→ **韌體契約**：充電器一律以 0x6A 存取；bring-up 時必須以 I²C 掃描確認 0x6A 與 0x6B 各回應且身份正確
（讀充電器 `PART_INFORMATION`、讀 IMU `WHO_AM_I`）。此項列入 WP9 台架清單。

## 5. 上拉域擁有權

### 5.1 擁有權規則

**核心板單獨擁有 I²C 上拉。** 轉接板**禁止**再掛 I²C 上拉電阻。

理由：
- 上拉並聯會使等效阻值下降、上升緣過快，且總阻值隨插上哪塊轉接板而變，無法一致驗證
- 深睡靜態電流必須由單一擁有者可預測地計算

| 網路 | 上拉位置 | 上拉電源域 | 擁有者 |
| --- | --- | --- | --- |
| `I2C_SCL` | 核心板 | `3V3_AON` | 核心板 |
| `I2C_SDA` | 核心板 | `3V3_AON` | 核心板 |
| `EXP_INT`（含RTC、核心／適配器TCA wired-OR） | R502=100k唯一已裝上拉；R305 DNP備位，不並裝 | `3V3_AON` | 核心板；適配器不得另加上拉 |
| `KEY_POWER_MCU` | 核心板 | `3V3_AON` | 核心板 |

常供匯流排上拉電源域一律為 `3V3_AON`（見 [power-tree.md](power-tree.md)）。**禁止**把常供 I²C 上拉接到
任何可被關閉的軌。本批不設TUSB I²C bus switch；OUT1/2由本地4.7k上拉，经非反相開漏AUP2G07到AON側
R602/R603各10k上拉。U202非failsafe端不得裸接AON；隔離器的有限漏電仍須計算與實測。

### 5.2 上拉阻值

阻值計算需要匯流排總電容（含板間連接器與 FPC），而 FPC 長度屬 WP1 未凍結輸入。

→ 本節**不凍結最終I²C上拉阻值**（IRQ裝配候選另見§5.1）。凍結的是：
- 上拉由核心板單獨擁有
- 上拉域為 `3V3_AON`
- 佈局預留可換阻值的封裝（0402），bring-up 期間以實測上升緣定案
- 深睡預算須涵蓋最終阻值及接收器漏電；理想上拉電阻在空閒高時無壓差，不代表整個接口零負載

### 5.3 TUSB320LI VBUS-only 與未上電隔離門

2026-09-08 工程候選覆蓋先前待選項：TPS70933由VBUS產生`3V3_USB_CC`；R205=887k±1%；
ADDR NC選GPIO、EN_N/PORT固定接GND；OUT1/2經本地4.7k上拉與AUP2G07送P16/P17，OUT3/ID不用。
按OUT1/2順序，HH未接、HL默認電流、LH 1.5A、LL 3A；GPIO2監控有效及初始化穩定前不可用編碼放大充電。
U202沒有獨立VDD_I2C，非failsafe端仍不得直接接AON；四象限、半掉電、ramp和漏電資格保持開啟。

「VBUS-only」只表示U202無主動電池供電，不表示整個接口零電池負載。本批在VBUS=0、AON有效、CC rail已穩定
放電的指定穩態预算為AUP2G07雙路保守2.4µA + AUP1G17輸入0.5µA + ICC0.9µA = **3.8µA**。
2.4µA是Ioff與ΔIoff保守相加假設，不是廠家新的全狀態保證；0.2–0.8V半掉電及ramp另測。47k+1%=47.47k泄放在2.9µA
假設注入下約0.1377V，不能證明整段衰減必然受控。`ISHUTDOWN`與`IUNATTACHED_UFP`是U202已供電
條件，不能機械加入拔線深睡，也不能據此漏掉上述隔離／監控負載。

來源：TUSB320LI SLLSEP2D；VBUS-only 系統邊界見任務 `design.md` §3。

### 5.4 轉接板未插入時

轉接板未插入時，匯流排上只有核心板裝置，上拉仍由核心板提供，匯流排完整可用。
→ 核心板可在無轉接板情況下獨立 bring-up（充電、燃料計、RTC、IMU、USB、SD、音訊全部可測）。
此性質列入 WP9 台架順序：先驗核心板，再插轉接板。

## 6. 位址掃描期望值（bring-up 契約）

核心板單獨上電，固定節點應回應：

```
0x20  TCA9535 #1
0x52  RV-3028-C7
0x55  BQ27427
0x6A  BQ25628E
0x6B  LSM6DSO32X
```

VBUS absent/present 的核心期望集合皆為 **0x20/0x52/0x55/0x6A/0x6B**。本批TUSB不響應0x47/0x67/0x60，
插拔不得改變此集合；實際適配器地址依其資格另加。AON匯流排在拔線時仍可用及跨域漏電須台架驗證。
