# thin18-domestic layout 优化空间检查（2026-09-28）

**结论先说**：布线已电气完成（`routing142` 原生核验 **0 违规 / 0 unconnected / 0 parity**），
**但布局层有 2 项高优先级优化空间 + 3 项中低优先级**。最高优先级的一条是 **In1 参考平面被
1,224 mm 信号走线穿过** —— 那是 option 1（启用 In1 作布线层）的代价，现在板子干净了，有条件
把它挪走。

> 核验方式：`routing142.kicad_pcb` + `routing141.kicad_dru`，配 canonical `.kicad_pro` 与完整库
> （缺库/缺工程文件会伪造出几百项 `lib_footprint_issues` / `track_width` 等幽灵违规，见 HANDOFF 第 6 节）。

## 二、发现与建议（按优先级）

### 🔴 P1 — In1 的 GND 平面被 1,224 mm 信号穿越

**证据**：In1.Cu 上有一块**已填充的 GND zone**（29 个填充多边形），同时承担 **1,224.5 mm** 信号走线。

**为什么重要**：F.Cu / B.Cu 上的走线参考平面就是 In1。信号穿过平面会在参考面上开槽，
跨槽走线会造成阻抗突变与回流路径绕行 —— **DRC 不会报这个**，它属于 SI/EMC 范畴。

**可选做法**：
1. **把 In1 上的信号挪走**（首选）：板子现在只剩 39% 空闲但顶带 761 mm² 集中，配合下面的 P2
   一起做，通常能把大部分 In1 信号迁到 F/B/In2；
2. 保留但**做参考面修补**：跨槽处加缝合过孔 + 保证回流路径连续（需要 SI 仿真确认）；
3. 接受现状，但**在叠层文档里明确 In1 是"信号+平面混合层"**（不要标成纯 GND）。

### 🔴 P1 — 布局严重不均衡（P2）

**证据**：顶带（y4–30）还空着 **761 mm²（45.7%）**，而 J802 带只剩 **40 mm²（6.2%）**、
中段 0.8% —— 全板 39% 空闲里有一半堆在顶带。

**为什么重要**：这是绕行与 In1 占用共同的**根因**。板子被元件挤到"没有别的路可走"，
才把信号推上 In1、才绕出 400 mm 的 3V3_AON。

**可选做法**：把 J802 带/中段的**低针脚数小件**（0603/0402 的 R/C、TP）迁往顶带空区；
一次成组的搬移比零散搬移有效（2026-09-22 已验证：局部 12mm 内无位，必须成组远迁）。
**代价**：需要重布受影响的网；有 DRC 四道门兜底，可分批验证。

### 🟡 P2 — 绕行异常的网络

| 网络 | 走线长 | 直线跨距 | 绕行比 |
|---|---|---|---|
| **3V3_AON** | 406.6 mm | 131.9 mm | **3.08** ✗ |
| I2C_SDA | 278.9 | 117.5 | 2.37 |
| I2C_SCL | 252.9 | 112.1 | 2.26 |
| VBUS_USB | 223.5 | 128.3 | 1.74 |
| UART0_RX / TX | 192.4 / 185.3 | 120.4 / 121.3 | 1.60 / 1.53 |

**为什么重要**：3V3_AON 绕了 3 倍 —— 对电源而言是**压降与噪声耦合**，对 I2C 是**上升沿完整性**。
**可选做法**：① 3V3 类改"平面/短桩"供电策略（现在 0.3mm 走线 1,004 段）；② I2C 双线并行缩短，
或把上拉位置靠近主控。

### 🟡 P2 — 0.15 mm 规则债（10 条例外 + 74% 走线在 0.15 mm）

**证据**：`.kicad_dru` 13 条规则里 10 条是 `min 0.15mm`；实测线宽 74% 落在 0.15 mm。

**为什么重要**：0.15 mm 对 1 oz 常规厂可做，但**良率/成本/CAF 余量**都比 0.2 紧。
EVT 阶段可接受，**转小批前需要按目标板厂重新确认**（这批例外是 2026-09-22 为收敛而授权的，
清单在 `.kicad_dru` 与 README 中）。
**可选做法**：转小批前做一次"0.15mm 例外清单复核" —— 逐条判断能否回到 0.20。

### 🟢 P3 — 叠层/层命名不一致

In1 在板上叫 **"Ground Layer 1"**、类型是 `signal`，实际是 GND 平面 + 1.2m 信号。
另外 In2.Cu **没有任何 zone**（纯信号层），而 In1 有平面 —— 参考面分布与命名不对称。
**做法**：写清叠层意图（哪层是参考面、哪层允许穿越），或在工艺文件里改名。

## 三、不建议动的

- **6.736 mm 顶边距契约**（开窗移/缩）：属机构契约，需机构重新确认，不在 layout 优化范围；
- **ANT501 预留区**：keepout 已正确生效（实测无 items_not_allowed），不要把器件搬进去；
- **把带内净空放宽到 0.15 mm 以下**：0.075 mm 级别不可制造。

---

## 四、如果想动手，建议的次序

1. **P1-2（布局再平衡）先行** —— 它是其他几条的根因，且能顺带缓解 P1-1；
2. 再按 **P1-1** 把 In1 信号迁走（此时容量才真正腾出来）；
3. 然后做 **P2-1 绕行网络**（3V3_AON / I2C）与 **P2-2 规则债复核**。

每一步都沿用既有验收口径：**原生 DRC 0 违规 / 0 parity / opens 不增 / 无回归**，
板子按 `WIP / NOT FOR FABRICATION` 标记，增量以检查点（`routingNNN`）固化。
