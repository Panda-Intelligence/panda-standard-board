# P1-1 执行方案：把信号搬离 In1 参考平面（2026-09-28）

**目标**：In1.Cu 是本堆叠的 **GND 参考平面**（已填充 zone，29 块填充多边形），但它同时承载
**1,224.5 mm 信号**（1,631 段，24 条网）。这些走线在参考面上开槽，是所有跨槽走线的回流路径风险 ——
**DRC 不报**，属 SI/EMC 范畴，是当前 layout 最大的单点问题。

**为什么现在能做**：布线已电气完成（0 违规 / 0 unconnected / 0 parity），板上有 39% 非开窗空闲面积
（顶带 761 mm² 最集中），有容量把 In1 上的信号改走 F/B/In2。

---

**关键判读**：前 10 条占 **~90%**；其中 **I2C_SCL（5.16mm/段）与 EXP_INT（3.70mm/段）是连续长走线**，
是"真正占用平面"的部分；而 EPD16_CS / EPD16_VGL / I2S_LRCLK / UART0_RX（0.3–0.8mm/段）是**过路短跳**，
每跳 = 2 个过孔 + 一条槽 —— 数量多、单段短，是"碎片化"来源。

---

## 二、两条可选路径

### 路径 A（推荐）：给 In1 加布线代价，逐网重布

1. 在路由器模型里把 **In1 的信号代价抬高**（例如层代价 ×3，与 In2 的非对称）；
2. 对上述 ~10 条网**逐网 rip → 重布**（沿用既有 `driver.py` 单网事务，
   验收门不变：0 违规 / 0 parity / opens 不增 / 无回归）；
3. 目标是 In1 信号长度 **1,224 mm → 300 mm 以内**，且**优先消灭碎跳**（段数 1,631 → < 300）。

**代价**：每条网一次事务（可短批跑）；**风险**：重布可能失败（则该网保留现状，不算回归）。
**注意**：GND 的 44.2mm/3 段是平面缝合，**不要动**。

### 路径 B（保守）：接受现状 + 参考面修补

跨槽处补缝合过孔、保证回流连续；并在叠层文档里把 In1 标注为"平面 + 受限信号"。
**代价**：需要 SI 仿真确认；**收益**：不动布线，但平面完整性只被"缓解"而非"修复"。

---

## 三、建议次序与验收

1. 先做**路径 A 的前 2 条**（I2C_SCL、EXP_INT —— 连续长走线、收益最直接）验证机制；
2. 再处理碎跳类（EPD16_CS / VGL / I2S_LRCLK / UART0_RX）；
3. GPIO0 / KEY_POWER_MCU / CC_OUT1_AON 视 1–2 的结果决定。

**验收（与既有检查点同口径）**：原生 DRC 0 违规 / 0 parity / unconnected 不增 / 无回归；
每条成功后出 `routingNNN` 检查点；全过程标 `WIP / NOT FOR FABRICATION`。

**不做的事**：不动 6.736 mm 顶边距契约；不把净空放宽到 0.15 mm 以下；不改 In1 的平面属性（它是参考面）。

## 四、附：布局再平衡（P1-2）的可动清单（备用）

若走路径 A 后仍有容量瓶颈，再动布局。按"慢速网 + 非去耦 + 非高速"筛出的可动件共 **16 个 / 63.1 mm²**，
其中 14 个就在 J802 带内：

```
C805/C806/C807/C808/C809/C810   EPD 各电源轨电容（6×6.93 mm²）
R803/R804/R805/R806/R807/R808
R810/R812/R813/R814             EPD 串阻/分压（10 个，1.89–4.55 mm²）
```

必须**留在原地**的（已核）：C804（BOOST 开关环路，面积不能拉长）、R211/R208/R212/R528（电源/去耦）、
R529/R530（USB 串阻）、C801/C811/C813（3V3_EPD_LOGIC 去耦）。
