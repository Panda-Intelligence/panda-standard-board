# 嘉立创优惠券适用性审计 — Thin18 routing142

日期：2026-09-29
对象：Thin18 `routing142`
性质：优惠条件工程审计，不代表嘉立创订单系统最终核券结果。

## 结论

当前 Thin18 **不满足“10×10 cm 以内”类 PCB 免费打样 / PCB+SMT 券的基本尺寸条件**。

主要阻塞：

- 当前 PCB 外形：**70.0 × 128.1 mm**
- 优惠基本条件：长、宽均需在 **100 × 100 mm** 范围内
- 因此 128.1 mm 一边超限 28.1 mm。

开源本身不会覆盖此尺寸限制。

## 沉金面积保守上界

整板矩形面积：

`70.0 × 128.1 = 8967 mm²`

20% 门槛：

`1793.4 mm²`

从 routing142 KiCad PCB 的 651 个焊盘读取阻焊开窗，并把圆形、椭圆、圆角矩形全部按更大的外接矩形计入，得到保守上界：

- F.Mask：`423.08 mm²`，约整板面积 **4.72%**
- B.Mask：`73.26 mm²`，约 **0.82%**
- 两面简单合计：`496.34 mm²`，约 **5.53%**

该算法有意高估常规焊盘面积，因此仍显著低于20%。最终受镀面积以嘉立创上传后的 Gerber/DFM 计算为准。

## 订单建议

如果使用当前 routing142：

1. 不要为了免费券而把 128.1 mm 主板强行压缩到 100 mm；这会变成产品架构/机构级改版。
2. 选择 **4 层 / 0.8 mm / 绿油 / 单片 5 PCS**。
3. 如使用沉金类优惠，选择 **ENIG**；上传后再次确认平台报告的沉金面积 <20%。
4. 不选择拼版/代拼，否则不满足“单片出货”的券规则。
5. 如果券是“嘉立创 EDA 专用券”，当前 KiCad 文件不要强行套用；应使用通用券，或另外建立受控的嘉立创 EDA 原生版本并重新做等价性验证。
6. 如果券是 PCB+SMT，必须选择 SMT；但当前生产 BOM / LCSC 料号 / SMT 装配资格仍未闭合，不应为了用券提前下 PCBA。
7. 开源文件若在下单页显示“拆单 / 已被其他客户享受优惠”等提示，则按当月规则不能再次享受该文件优惠；这个状态无法由 Git 仓库离线验证。

## 当前更合理的优惠路径

当前板型优先寻找：

- 不受 100×100 mm 限制的开源项目专项支持 / 活动资源；
- 普通付费裸板 + SMT / 元器件专项优惠；
- 后续产品若自然出现 ≤100×100 mm 的子板，再使用常规免费打样券。

不建议单纯为了节省一次 PCB 打样费用，把 70×128.1 mm 主板拆板或缩短。
