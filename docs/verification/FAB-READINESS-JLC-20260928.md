# 嘉立创打样就绪评估（2026-09-28）

**一句话结论：可以在嘉立创的常规 4 层工艺直接打样** —— 所有最小特征都达标（其中环宽正好卡在
他们的 4–6 层下限，无余量），**Gerber/钻孔文件已导出**，路径见文末。剩下是 3 项工艺参数选择 +
2 项必须明确"未验证"的边界。

> 口径说明：本评估只覆盖**裸板可制造性**。DRC 是**我们自己的规则集**下的检查，不等于工艺鉴定；
> 也不含 SI/EMC、装配、机械配合。全部标 `WIP / NOT FOR FABRICATION`。

## 一、实测 vs 嘉立创能力（4 层常规工艺）

| 项目 | 本板实测 | 嘉立创 4–6 层能力 | 判定 |
|---|---|---|---|
| 层数 | 4（F/In1/In2/B，仅通孔） | 4 层常规 | ✅ |
| 板厚 | **0.8 mm** | 0.8 是标准备料（0.4–2.0 可选） | ✅ |
| 外形 | 70.0 × 128.1 mm | 4 层最大 663×593 mm | ✅ |
| 最小线宽/线距 | **0.15 mm** | **0.09 mm**（3.5 mil） | ✅ 余量大 |
| 最小过孔钻孔 | **0.2 mm** | 0.15 mm 起（推荐 ≥0.2） | ✅ 正好推荐值 |
| 最小环宽 | **0.100 mm**（0.4 盘 / 0.2 孔，514 个） | **0.10 mm** | ✅ **正好达标，无余量** |
| 过孔类型 | 全部通孔，无盲埋孔 | 通孔常规 | ✅ |
| 铜到板边 | 最小 **0.5 mm**（J201 屏蔽脚） | 通常要求 ≥0.2–0.3 mm | ✅ |
| NPTH 孔 | 0.991 / 1.6 mm | NPTH 槽 ≥1.0 mm、钻孔不限 | ✅ |
| 丝印/阻焊 | 单面丝印 + 双面阻焊 | 常规 | ✅ |

**注意**：环宽 0.100 mm 恰好等于嘉立创 4–6 层的下限（1–2 层是 0.13）。**不要在下单前把过孔改小**
（例如换 0.15 孔），那会掉出常规工艺。

## 二、下单时需要在嘉立创选的参数

| 参数 | 建议值 | 理由 |
|---|---|---|
| 层数 / 板厚 | 4 层 / **0.8 mm** | 与设计一致；0.8 是标准备料，无加价 |
| 铜厚 | 外层 1 oz / 内层 0.5 oz | 设计按 1oz 外层（0.15mm 线宽足够） |
| 层压结构 | 用嘉立创标准 4 层结构 | **不要自定义**，否则优先按他们推荐结构走 |
| 阻抗控制 | **按需**（如需 USB/时钟阻抗，勾选 +/−10%） | 设计未指定阻抗，属未验证项 |
| 表面处理 | 建议 **沉金 ENIG** | 0.4/0.2 过孔 + 细间距焊盘，喷锡易堵孔；板厚 0.8 不受"≤0.4 不做喷锡"限制 |
| 阻焊/丝印颜色 | 按外观要求 | 与电气无关 |
| 拼版/工艺边 | 嘉立创代拼（默认 MARK 加在工艺边） | 单板 70×128，拼版可省板费 |

## 三、需要与厂家确认的 3 项

1. **J201 的贴板边 SMT 焊盘**：规则集里有一条 `edge_clearance min 0 mm` 的例外（USB-C 连接器的
   边缘焊盘）。实测焊盘到板边 **0.5 mm**，常规工艺应无问题；若其 DFM 工具报此项，出示该连接器
   规格书（厂商要求的边缘焊盘形式）说明即可。
2. **显示开窗的圆角半径**：Edge.Cuts 有 8 段圆弧。嘉立创最小锣刀直径 **0.8 mm**，请确认开窗内圆角
   ≥0.8 mm（否则要放大圆角或改走"锣槽"）。
3. **U201 的 4 个自定义形状焊盘**（标称 0.01 mm，真实铜在自定义图元里）。请在嘉立创的 Gerber
   预览里确认这 4 个焊盘成像正确 —— 若显示异常，需把该封装的自定义图元改为标准矩形。

## 四、**未验证**的边界（不要在打样评审里当成已通过）

- **SI / EMC**：未做仿真或实测。特别是布局评审里那条 **In1 参考平面被 1,224 mm 信号穿越**（方案见
  `PLAN-In1-CLEANUP-20260928.md`）；
- **阻抗**：设计未指定受控阻抗网络；
- **装配（PCBA）**：BOM/位号/贴片可达性未审（本次若只打**裸板**则不影响）；
- **机械**：0.8 mm 板厚的成品公差是 **±0.1 mm**（0.7–0.9），薄板配合（顶边距 6.736 mm 契约）需按
  **最坏情况 ±0.1 mm** 复核；
- **电气功能**：未做网表—实物对照、未做飞针/夹具测试定义。
