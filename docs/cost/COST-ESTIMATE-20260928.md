## 三、元件：**目前没有报价**（这是最大的一块）

- 工程目录 `thin18-domestic/cost-down-20260928/grouped-rfq-bom.csv` 里,
  `binding_CNY_unit_quote_*` 三列**全为空**,状态是 `RFQ_EXACT_MPN_REQUIRED`
  —— 即**精确订货号还没定,自然没有价格**;
- 他们自己的规则写得很清楚：**"价格空白或 null 代表未知,绝不是零元"**；
- 参考量级（**仅数量级,不能当报价**）：202 个元件里 R 83 / C 51 / TP 26 / U 20 / J 7 / D 5 / H 4 / L 3 / SW 2 / Q 1
  —— 被动件按 LCSC 常规单价（几分到几毛）合计约 **¥5–20/片**；
  **真正的成本在 IC 与连接器**（U 20 个 + J 7 个：屏连接器、USB-C、电源/电量计、逻辑等），
  这部分**必须等 RFQ 回来**才能算。

**⇒ 装配样品（PCBA）的单价 = 上面 ¥90–200 + 元件（待报价）**。
按同类小尺寸墨水屏板的经验,**元件通常会超过板子本身**（尤其屏连接器与电源 IC）——但这句是经验,
不是数据,请以 RFQ 为准。

- **元件成本未知**（RFQ 未回）；**运费/关税/治具/测试**未计；
- 与本板设计相关的**未验证项**（SI/EMC、阻抗、0.8mm ±0.1mm 公差对薄板配合）见
  `FAB-READINESS-JLC-20260928.md`,不因报价而改变；
- 打样价格随嘉立创的活动/备料/结构选择变化,以在线计价为准。
